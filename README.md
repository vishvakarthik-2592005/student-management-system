# Student Management System

A simple Student Management System built using Python and MySQL.

# Features

- Add Student
- View Students
- Update Student
- Delete Student
- Search Student

# Technologies Used

- Python
- MySQL
- mysql-connector-python

# Project Structure

Student-Management-System/
│── main.py
│── student.py
│── database.py
│── requirements.txt
│── README.md

# How to Run

1. Install dependencies

pip install -r requirements.txt

2. Start MySQL

3. Run

python main.py
